# TalkSignal

특정 카카오톡 채팅방에 안 읽은 메시지가 있으면 macOS 메뉴바에 표시하는 개인용 앱입니다.

## 사용 방법

1. `TalkSignal.app`을 실행합니다. Dock 아이콘 없이 메뉴바에 나타납니다.
2. 설정에서 **감지할 채팅방 이름**을 띄어쓰기·이모지까지 그대로 입력합니다.
3. 말풍선, 하트, 별, 종, 편지, 발자국, 달, 사람 중 아이콘을 선택하거나 이모지 하나를 입력합니다.
4. **저장하고 적용**을 누릅니다.
5. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 **TalkSignal**을 허용합니다. 설정 화면의 버튼으로 해당 위치를 열 수 있습니다. 목록에 없다면 `+`로 앱을 추가합니다.
6. 카카오톡 채팅 목록을 열어 둡니다. **노란색 버튼으로 최소화해도 작동합니다. 빨간색 버튼으로 창을 닫으면 감지가 멈춥니다.**

| 표시 | 의미 |
| --- | --- |
| 선택한 아이콘 + 분홍색 점 | 지정한 채팅방에 안 읽은 메시지 있음 |
| 선택한 아이콘만 표시 | 조회 성공, 안 읽은 메시지 없음 |
| 선택한 아이콘 + 주황색 점 | 권한 부족, 카톡 종료, 창 닫힘, 대상 미발견 등으로 감지 불가 |

안 읽은 숫자 표시는 설정에서 켜고 끌 수 있습니다. 아이콘을 클릭하면 감지 상태, 최근 확인 시각, 설정, 수동 확인, 표시 미리보기, 종료 메뉴가 나옵니다. 읽음 상태는 다음 조회에 반영됩니다.

## 동작 및 개인정보

- 카카오톡의 macOS 접근성 정보를 읽기 전용으로 조회합니다. 카카오톡을 실행하거나 활성화·클릭·스크롤하지 않습니다.
- 메시지 미리보기 텍스트 영역에 들어가지 않습니다. 채팅 행의 이름·시각·안 읽은 배지 같은 메타데이터만 검사합니다.
- 감지 대상 이름, 아이콘, 숫자 표시 설정만 이 Mac의 UserDefaults에 저장합니다. 메시지 본문·수신 기록을 저장하지 않으며 네트워크 요청·분석 SDK·외부 서버가 없습니다.
- 기본 조회 간격은 3초입니다. 조회는 백그라운드 직렬 큐에서 실행되며 겹쳐 실행하지 않습니다. 발견한 행은 이름을 재검증해 재사용합니다. 느린 응답 때문에 실제 간격이 길어질 수 있습니다.
- 공식 Kakao API로 개인 메시지를 수신하는 앱이 아닙니다. Kakao와 무관한 개인 프로젝트입니다.

## 제약

- **현재 Mac의 KakaoTalk UI 구조에 맞춘 초기 버전**입니다. 카카오톡 업데이트로 구조가 바뀌면 수정이 필요할 수 있습니다.
- 이름이 동일한 채팅방은 구별하지 못합니다. 카카오톡에서 고유한 표시 이름을 사용하세요. 이름을 바꾸면 앱 설정도 바꿔야 합니다.
- 채팅 목록에서 접근성으로 노출되는 행만 읽습니다. 대상을 못 찾으면 읽음으로 간주하지 않고 감지 불가 상태로 표시합니다. 대상 채팅방을 상단 고정하는 편이 안정적입니다.
- 컴퓨터가 잠들거나 로그아웃되어 있으면 실시간으로 감지하지 못합니다.
- 재부팅 자동 실행은 기본으로 등록하지 않습니다. 필요하면 macOS 로그인 항목에 앱을 추가할 수 있습니다.
- Developer ID 배포 서명/공증은 포함하지 않았습니다. 빌드 스크립트는 로컬 ad-hoc 서명을 사용합니다. 소스를 다시 빌드하거나 앱 위치를 변경하면 접근성 권한을 다시 설정해야 할 수 있습니다.

## 빌드 및 테스트

macOS 13 이상, Xcode Command Line Tools의 Swift 컴파일러가 필요합니다. 설치된 Mac의 아키텍처로 빌드합니다. 외부 라이브러리 의존성은 없습니다.

```sh
./scripts/build.sh
./scripts/test.sh
open build/TalkSignal.app
```

앱 경로: `build/TalkSignal.app`

읽기 전용 진단 모드(메시지 본문 출력 없음):

```sh
build/TalkSignal.app/Contents/MacOS/TalkSignal --probe '대상 채팅방 이름'
```

진단 모드는 두 번 조회해 초기 탐색과 캐시 조회 시간을 출력합니다. 실행 주체의 접근성 권한이 필요합니다. 터미널의 권한으로 진단이 성공해도 앱 자체 권한은 별도로 필요할 수 있습니다.

## 구조

- `Sources/Core.swift`: 이름 일치, 배지 파싱, 감지 상태
- `Sources/ChatReader.swift`: 카카오톡 접근성 읽기, 창·권한 확인
- `Sources/App.swift`: 메뉴바, 설정 창, 로컬 설정, 조회 스케줄
- `Tests/CoreTests.swift`: 이름 오인식, 단체방 인원수, 배지 상한 및 잘못된 값에 대한 회귀 검사

개인 채팅 이름이나 테스트 대화 내용은 저장소에 넣지 마세요. `build/`와 로컬 앱 설정은 버전 관리하지 않습니다.
