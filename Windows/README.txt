TalkSignal Windows 준비판 0.1.0 (Windows 11 x64용)

중요: 실제 카카오톡 안 읽음 감지는 아직 구현되지 않았습니다.
이 앱은 Mac 완성판의 기능이 모두 옮겨진 제품이 아닙니다.
카톡 창을 닫은 상태의 감지와 폰에서 읽으면 표시가 꺼지는 기능은
실제 Windows 카톡의 데이터 연동 개발 및 검증이 필요합니다.

실행
1. 압축을 전부 풀고 TalkSignal.exe를 실행합니다.
2. 이름, 아이콘, 숫자 표시를 설정합니다.
3. Windows 시작 시 실행은 원하는 경우 체크합니다. 관리자 권한은 필요 없습니다.
4. 트레이 아이콘이 안 보이면 작업표시줄 오른쪽의 숨겨진 아이콘(∧)을 확인하세요.
5. 우클릭하면 설정, 표시 미리보기, 체험, 종료 메뉴가 나옵니다.

체험
Try-Demo.cmd 또는 앱의 '수신·읽음 표시 체험'을 사용합니다.
'수신 3개', '읽음 0개', '조회 실패'는 가상 데이터입니다.
실제 카톡과 연결하지 않고 트레이 아이콘의 동작만 시험합니다.
체험 창을 닫으면 실제 연동 대기 표시로 돌아갑니다.
주황색 점은 미연동/확인 불가이며, 안 읽은 메시지가 없다는 뜻이 아닙니다.

아이콘 클릭
같은 이름의 카톡 대화창이 이미 열려 있으면 그 창을 앞으로 가져옵니다.
열린 창이 없으면 카카오톡 메인 앱을 엽니다.
닫힌 대상 방을 검색해서 바로 여는 기능은 아직 구현되지 않았습니다.

설정과 제거
설정: %LOCALAPPDATA%\TalkSignal\settings.json
자동 실행: 현재 사용자 레지스트리 Run의 TalkSignal 값만 사용합니다.
제거 전에 자동 실행을 해제하고 트레이 메뉴에서 앱을 종료한 뒤 폴더를 삭제하세요.
앱 위치를 옮겼다면 자동 실행 체크를 해제했다 다시 저장하세요.

개인정보
이 준비판은 카톡 DB, 메시지 본문, 알림 기록, 프로세스 메모리를 읽지 않습니다.
명시적으로 클릭했을 때 카톡의 최상위 창 제목만 확인합니다.
외부 전송, 분석 SDK, 메시지 보내기, 관리자 권한 요청은 없습니다.
설정에는 이름/아이콘/숫자 옵션만 저장합니다.

환경과 검증
.NET 런타임 포함. Windows에 .NET을 따로 설치할 필요 없습니다.
Windows Server 2025 원격 VM에서 EXE 실행과 UI/설정/상태 테스트를 수행합니다.
실제 Windows 11 PC, 카톡 로그인, 폰과의 동기화 검증과는 다릅니다.
코드 서명 인증서 없는 개인 개발판이므로 Windows가 알 수 없는 앱으로 표시할 수 있습니다.
